# QueryLab Design System — 使用规范（guidelines）

> 版本：v1.0（2026-09-02）
> 适用范围：V1 原型（prototype/v1-new/app-prototype.html）与后续重开发实现。
> 上游依据：`docs/07_design_system/TOKEN.md`、`components.md`、`patterns.md`、`assets.md`；P4 审查（docs/06_review/PRODUCT_REVIEW.md）B 类清单。

---

## 1. 总则

1. **单一主题**：深色单主题（VS Code 风格）；不引入亮色主题切换（旧项目无此能力，属新增功能）。
2. **令牌唯一来源**：一切颜色/字号/间距/圆角引用 `tokens.md` CSS 变量（`--ql-*`），禁止裸值散写（旧项目 `#3e3e3e` 散写 85 处为反面教材）。
3. **业务组件优先**：优先复用 `components.md` 33 项记录；新组件先登记再使用。
4. **交互一致性**：查询-结果流转、表单校验、危险确认、空态、加载、导出、编辑门禁等场景必须遵循 `patterns.md` 对应模式，不得页面各自发明。
5. **溯源**：任何与本 DS 冲突的旧项目行为，以本 DS（经 P4 审查定稿）为准；真实缺陷不复刻（见 §6）。

## 2. 布局规范

- 窗口：1400×900 默认 / 1000×600 最小（tauri.conf.json）。
- 三段式：顶栏 48px → 主区（侧栏 280px + 工作区弹性）→ 状态栏 24px（`--ql-primary` 底）。
- 工作区查询视图纵向两栏：编辑器（上，弹性）/ 结果面板（下，min 120px）；历史侧栏 320px 左侧挤入。
- 侧滑面板 420px；模态确认框 420px；表单弹窗 ~500px。
- 层级 z-index：内容 < 面板 < 右键菜单 < Toast(2000) < 确认遮罩(2100)。

## 3. 颜色使用规范

1. 语义优先：错误→`--ql-danger` 系；成功→`--ql-success` 系；信息→`--ql-info-bg`；禁止用品牌蓝表达错误。
2. 品牌蓝 `--ql-primary` 用于：主操作（运行/保存/主按钮）、选中态、状态栏、焦点环；不得用于大面背景（状态栏 24px 除外）。
3. 视图身份色（`--ql-view-*`）仅用于视图切换器 active 态与对应视图头部点缀，不得混用。
4. 值类型渲染四色（null/number/string/bytes）只用于数据单元格；主键紫（`--ql-pk-*`）只用于主键列。
5. 文本对比度：正文 `--ql-text-primary`（#d4d4d4 on #1e1e1e ≈ 9.4:1）；次要文本 `--ql-text-secondary` 仅用于非关键信息。

## 4. 文案规范

1. 加载/空态/错误文案沿用源码原文基准（patterns P4/P5/P6 表），不得随意改写（保持与旧项目可对照）。
2. 中英混排：操作动词中文（运行/格式化/导出），状态消息保留英文技术串（Ready / No connection / Query completed in Xms——源码事实）。
3. 危险文案必须含「不可撤销」或后果说明（源码范式）。
4. 数量反馈带数字（「成功删除 N 行」「Batch completed: N statements, Xms」）。
5. V1 修复类文案必须标注修复来源（如「修复：旧项目按 ; 简单分句」），保证评审可溯源。

## 5. 键盘与可达性

1. 快捷键集固定：Ctrl+Enter 执行 / Ctrl+S 格式化 / Ctrl+H 历史 / Ctrl+K 清空 / F1 片段 / Ctrl+F 搜索；单元格 Enter 保存 / Esc 取消 /（网格）Tab 跳列保留值（B9）。
2. 全局 Esc 关闭最上层弹窗/菜单；遮罩点击=取消。
3. 弹窗 role=dialog + aria-modal；图标 aria-hidden，语义由文本承担。
4. 焦点：连接列表 hover 出现的操作按钮必须键盘可达（focus 显现）。

## 6. 缺陷不复刻清单（V1 强制）

以下旧项目真实缺陷，V1 一律按修复后规格呈现并在界面标注（P4 B 类）：

| 缺陷 | V1 规格 |
|------|---------|
| 编辑连接不重输密码清空钥匙串 | 密码留空=保持原密码（B1） |
| 按 `;` 简单分句 | 分句预览条 + 正确分句（B2） |
| 批量进度面板未接线 | 批量执行自动唤起进度面板（B3） |
| 导出文件名可空 | 文件名兜底规则（B4/P8） |
| 方言检测字段错配 | 按 driver 映射 MySQL 方言 + 徽标（B5） |
| diff SQL 预览不插值 | 正确插值目标库表名（B6） |
| 历史搜索无过滤 | 输入即过滤（B7） |
| 表名补全无来源 | FROM/JOIN 表名候选接 Schema 树（B8） |
| 网格 Tab 丢值 | Tab 保留值跳列（B9） |
| 结果只读静默 | 只读原因提示（B11） |
| exportLoading 恒 false | 导出按钮 loading 态 |

## 7. 禁止事项

1. 禁止新增商业功能（License/VIP、云同步、付费能力——C 类留档项不得擅自呈现）。
2. 禁止虚构未实现能力：外键展示、列名补全、索引编辑、查询取消、多 Tab、SSL/SSH 等 C 类项只能以「受限/规划中」标注，不得做成可用交互。
3. 禁止外链资源（CDN/字体/图标库）——单文件自包含。
4. 禁止用 emoji 作为功能图标（一律 C32 SVG）。
5. 禁止 alert/confirm/prompt（一律 C18/C19）。

## 8. 变更流程

- 修改令牌/组件/模式须先改 DS 文件（注明日期与原因），再改原型/代码。
- V1 原型每页必须标注「PAGE 编号 + 来源（PRD §/page-spec §/P4 B#）」，评审面板提供五态场景切换。
