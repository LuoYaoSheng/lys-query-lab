## 二、缺陷记录与修复（发现→修复→复验）

| # | 缺陷描述 | 定级 | 处理 | 复验 |
|---|----------|------|------|------|
| D1 | 评审入口「F019 历史·敏感 SQL 拦截提示」演示后，切回查询视图会触发自动重查，覆盖敏感提示文案 | 中 | 已修复：demoSensitiveHistory 改为直接切视图（不触发自动重查），提示保留 | PASS（实测提示「检测到可能包含敏感信息，本条 SQL 仅保留当前会话，不会写…」稳定显示） |
| D2 | （开发过程中自查发现）备份导入页目标库/先删表复选框事件引用了未暴露对象，会导致控件失效 | 高 | 已修复：改为暴露 backupImportDb/backupDropExisting 处理器 | PASS（实测选库与勾选均生效） |
| D3 | （开发过程中自查发现）连接表单「保存/测试」会以初始空值提交（未回读输入框） | 高 | 已修复：提交/测试前 syncConnForm 回读 DOM | PASS（保存流程实测通过） |

> 以上均为原型实现层缺陷，非产品逻辑缺陷；修复后 `node --check` 复验通过，浏览器复测通过。

## 三、非阻断备注（原型与旧项目的有意差异，如实声明）

1. **旧项目已知缺陷未复刻**：原型按交互规格的"预期行为"实现，不复刻逆向报告⑨中的缺陷（编辑连接不重输密码会清空钥匙串密码——原型在密码框 placeholder 中如实标注提醒；DataSync 修改列 SQL 预览 `{targetDatabase}` 不插值——原型正确插值；网格 Tab 键丢值——原型 Tab 保留当前值）。
2. **ALTER 预览弹窗**：旧项目编辑表保存直接执行 ALTER；原型增加"diff→ALTER 预览+确认"弹窗以便评审（对 F039 的可视化增强，不改变功能边界）。
3. **系统对话框模拟**：保存文件/打开文件对话框在浏览器中原型用统一确认层模拟（文案标明"系统保存对话框模拟"）；导出通过 Blob 触发浏览器下载。
4. **剪贴板**：file:// 下 navigator.clipboard 可能不可用，复制 SQL 会给出失败 toast（与真实限制一致）。
5. **PAGE012**：按旧项目事实以"未接线演示态"呈现（评审面板入口唤起），不虚构运行入口。
6. **F020 自动补全**：旧项目本身即受限（无列名、表名源未接线），原型以工具栏提示+帮助说明覆盖，不做超范围实现。
7. **加载场景锁定**：切到「加载中」场景后相关操作保持加载态（面板注明"场景锁定：切换场景库继续"），用于稳定评审加载视图。
